# Minha identidade na Web - Paulo Ferreira

**Nome de apresentação:** Paulo Ferreira

Projeto individual da disciplina Desenvolvimento Front-End para Web. A página principal apresenta minha trajetória de aprendizagem em programação e engenharia de IA complexa, além de interesses, objetivos, estudos, áudio e formulário demonstrativo. A página complementar conta como começou a Sypher & Umbra Limitada com Gustavo e Alify.

## Como abrir

1. Extraia a pasta completa, mantendo as subpastas `paginas`, `imagens`, `midias` e `capturas`.
2. Abra `index.html` em um navegador atualizado. Não é necessário instalar nada nem usar internet para as imagens e o áudio.
3. Use o menu ou o link no conteúdo para abrir `paginas/interesses.html` e o link de volta para retornar.

## Recursos usados

- HTML semântico (`header`, `nav`, `main`, `section`, `footer`), links internos e externos, listas, tabela, imagens com texto alternativo, áudio com controles e formulário demonstrativo.
- CSS básico em `estilo.css`, sem JavaScript, PHP ou banco de dados.
- Foto pessoal `imagens/paulo-ferreira.jpeg`, fornecida por Paulo Ferreira, e ilustração original `imagens/sypher-umbra.svg`, criada para este projeto. Não foram usados materiais visuais de terceiros.
- Áudio local `midias/rotina-de-estudos.wav`, com texto criado para o projeto e narração sintetizada pela voz Microsoft Maria Desktop (pt-BR), disponível no Windows. A transcrição está na página principal. Não foi usada mídia de terceiros.
- Links de estudo: [MDN - HTML](https://developer.mozilla.org/pt-BR/docs/Web/HTML) e [W3C - tutoriais de acessibilidade](https://www.w3.org/WAI/tutorials/).
