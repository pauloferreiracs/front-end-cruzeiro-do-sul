Classes e IDs na prática

Uma classe pode aparecer em vários elementos. Um ID identifica um elemento específico da página. Veja a diferença nos exemplos abaixo.

Elemento comum

Esta div não recebe a classe caixa nem o ID aviso.

Sou uma div sem a formatação da classe.

Classe reutilizada

A regra .caixa define o mesmo estilo para elementos diferentes.

Sou uma div com a classe caixa.
Sou um span com a mesma classe.

ID específico

O seletor #aviso acrescenta um destaque só a este elemento.

Tenho a classe caixa e o ID aviso.
